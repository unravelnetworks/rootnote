# Rootnote guide

Rootnote turns your findings and screenshots into an editable Word report. This guide shows how, using the example report built into Rootnote. Every example uses a fictional client and synthetic evidence.

New to Rootnote? Begin with **[Start here: make and keep a report](start-here/)**, a short walkthrough that ends with a saved project file and a Word report.
