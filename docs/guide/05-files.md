# Files, folders and recovery

Rootnote has no server and no account. Your work lives in files that you keep.

## Your files

- **Project file** (ends in `.rootnote.json`): the whole report, with its screenshots. Open it to keep working.
- **Exported report** (Word, Markdown, CSV or PDF): a copy made from the project. Editing it does not change the project.
- **Library file**: your reusable findings. See [the finding library](../findings/#reuse-findings-with-the-library).

Treat project files and reports as confidential client material.

## Save often

Choose **Save** or press Ctrl+S.

- **Chrome and Edge** ask where to save the first time, then save to the same file. The top bar shows **Saved to file**. **⋯ → Save as…** saves a new copy.
- **Firefox and Safari** download the file each time. The top bar shows **Download requested**.

In Chrome and Edge, if saving is cancelled or blocked, nothing is saved. To download a copy instead, choose **Download project file** from the menu (⋯) and check that it arrived.

## Where did my file go?

- **Saved to file:** it is where you chose in the save window.
- **Download requested:** open your browser's downloads list (Ctrl+J in most browsers) or your *Downloads* folder. Each save may add a number to the name, so open the newest one.
- If you opened the project from an engagement folder, it saves back into that folder.

## One folder per engagement

If you keep a folder per customer and engagement, Rootnote can list them:

```
Engagements\
  Brightwater Logistics\
    2026-10 Customer portal\
      customer-portal.rootnote.json
```

1. On the start screen choose **Or browse your engagement folders**, or **Engagements** in the list on the left.
2. Choose **Choose engagements folder…** and pick the top folder.
3. Choose **Open** next to an engagement.

In Chrome and Edge, saving and exporting then write into that folder, and Rootnote asks before replacing a file. **New engagement…** creates the folders for you. In Firefox and Safari, files go to your downloads instead.

If the list is empty, check the layout: one folder per customer, one per engagement inside it, and the project file directly in the engagement folder.

## Cloud folders

To keep reports in Google Drive, OneDrive or Dropbox, save into the folder their desktop app syncs. Rootnote itself never connects to them.

## Recovery drafts

Unsaved work lives only in the open tab. To be safe if the tab closes, you can turn on **Keep a recovery draft in this browser** (1) in **Check & export**. Rootnote then keeps a copy in this browser and offers it the next time you open Rootnote.

![The Keep a recovery draft in this browser switch, marked 1.](__IMG_RECOVERY__)

> **Warning:** A recovery draft is not a backup. It is not encrypted, it lives only in this browser, and clearing browser data removes it. Keep saving project files. Leave drafts off on shared computers, and in a browser where you open files from targets or tools.

Turning the switch off deletes the draft, and Rootnote tells you whether that worked. The [Privacy](/privacy/) page has the details.

## If a file will not open

**Open…** checks the whole file first. If it is damaged or not a Rootnote project, Rootnote says why and leaves your current work as it was.

If Rootnote says a project is too large to save, remove some text or screenshots. **Download original file** keeps the file you opened unchanged while you do that.
