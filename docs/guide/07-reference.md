# Limits, browsers and keys

The rules worth knowing, in one place.

## Limits

| Item | Limit |
|---|---|
| Findings per report | 20 |
| Screenshots per report | 30, PNG or JPEG, each up to about 2 MB |
| Project file | about 25 MB in total |
| References per finding | 20 |
| Your own report sections | 10 |
| Finding library | 500 entries, text only |

These limits reflect the report sizes we have tested, not a paid restriction. If you reach one, Rootnote says so and keeps your work as it was. If a limit gets in the way of your normal work, please tell us.

## Browsers

| Where | Status |
|---|---|
| Windows: Chrome, Edge, Firefox | Tested on desktop. |
| macOS: Safari | Checked by hand: writing, preview and Word export. Saves are downloads. |
| Phone-size layout | Checked in desktop emulation. This does not verify a real phone. |
| Phones | Opening the sample, navigation, the preview and this guide checked on an iPhone 11 Pro with Safari. Report writing and saving are not checked on phones; use a computer. |

On a phone, explore Rootnote and its sample report. To write and save reports, use a computer.

Have Word for Mac, LibreOffice, Linux or an Android phone? [Help us check](/help-us-check/) what has not been tested yet.

The Word file is made for Microsoft Word and LibreOffice Writer. Checks in Word for Windows, Word for Mac and LibreOffice are not finished yet, so open each report once in the program you deliver with before you send it. If a word processor reports a problem with the file, please tell us at support@unravelnetworks.com.

## Keyboard

| Keys | What they do |
|---|---|
| Ctrl+S (Cmd+S on a Mac) | Save the project |
| Ctrl+V | Paste a screenshot after the text box you are in |
| Escape | Close an open menu or help box |
| Tab, arrow keys, Enter | In the screenshot editor: reach the picture, move the selection, apply the tool |
| Shift + arrow keys | In the screenshot editor: resize the selection |
