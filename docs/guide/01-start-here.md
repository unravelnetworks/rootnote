# Start here: make and keep a report

You go once around the whole cycle with the example report: open it, change it, save it, open it again and export it to Word. Then you start your own report.

Use a phone to read this guide and explore the sample. The report-writing steps are intended for a computer.

## Open Rootnote

- **Online:** open [rootnote.unravelnetworks.com/app/](/app/) in Chrome, Edge, Firefox or Safari on a computer.
- **Offline:** download the zip from the [Rootnote home page](/), unzip it and open `rootnote.html`.

Both are the same app. Your report stays on your computer either way.

## 1. Open the sample

On the start screen, choose **Open the sample** (1).

![The Explore the sample card on the start screen, with the Open the sample button marked 1.](__IMG_START_SAMPLE__)

**You should see** a report for a fictional client, Brightwater Logistics, with eight findings. It is only an example: never send it to a client.

## 2. Find your way around

The list on the left holds the whole report:

1. **Details & cover:** the title, client and cover page.
2. **Findings:** one line per finding. The coloured letter is its severity (C critical, H high, M medium, L low, I informational).
3. **Preview report:** the report as pages.

![The section list on the left, with Details & cover marked 1, the first finding marked 2 and Preview report marked 3.](__IMG_NAV__)

Choose the first finding, *Password reset token disclosed in API response*, to see what a finding holds: severity, score, affected systems, description and screenshots.

## 3. Change the title

1. Choose **Details & cover**.
2. In **Report title** (1), add *(practice)* to the end of the title.

![The Details & cover page with the Report title box marked 1, showing "Customer Portal Security Assessment (practice)".](__IMG_TITLE__)

**You should see** **Unsaved changes** in the top bar. The change is only in the open report until you save it.

## 4. Save

Choose **Save** (1) at the top right.

![The top bar with Unsaved changes and the Save button marked 1.](__IMG_SAVE__)

- **Chrome and Edge** ask where to save. Pick a folder you will remember and keep the name, which ends in `.rootnote.json`. The top bar then shows **Saved to file**.
- **Firefox and Safari** download the file. The top bar shows **Download requested**: look for the file in your *Downloads* folder.

In Chrome and Edge, if saving is cancelled or blocked, nothing is saved. To download a copy instead, choose **Download project file** from the menu (⋯) and check that it arrived.

> **Warning:** The saved file is your report. Rootnote keeps no copy online, so keep the file safe and back it up.

## 5. Open it again

1. Reload the page.
2. On the start screen, choose **Open…** (1) and pick the file you saved.

![The Open a project card on the start screen, with the Open… button marked 1.](__IMG_OPEN__)

**You should see** your title with *(practice)* at the end. If it is missing, you probably opened an older file: check the file's name and time.

## 6. Preview the report

Choose **Preview report** in the list on the left.

![The Preview toolbar with the Go to list marked 1 and Print / Save as PDF marked 2.](__IMG_PREVIEW__)

- **Go to** (1) jumps to a section or finding.
- **Print / Save as PDF** (2) makes a PDF. In the print window, choose *Save as PDF* and turn off the browser's headers and footers.

The preview is close to the Word file, but Word decides the exact page breaks.

## 7. Export to Word

1. Choose **Check & export** at the top right and read the list. For this sample, the notes do not stop the export. For your own reports, follow any **Cannot export yet** message.
2. Choose **Save Word report…** or **Export Word report** (1), depending on your browser.

![The paper size buttons and the Export Word report button, marked 1.](__IMG_EXPORT__)

Open the file in Word. Changes you make in Word stay in Word; to change the report in Rootnote later, open your saved project file.

## 8. Start your own report

Reload the page and choose **New report** (1). It starts empty, so nothing from the sample comes along.

![The New report card on the start screen, with the New report button marked 1.](__IMG_NEW_REPORT__)
